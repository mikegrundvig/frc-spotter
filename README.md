# Spotter's Maven repository

`com.michaelgrundvig.frc:spotter-api` and `com.michaelgrundvig.frc:spotter-client`, under
`maven/`, published from each release's tag by `.github/workflows/release.yml` on `main`, and
served by GitHub Pages at https://mikegrundvig.github.io/frc-spotter/maven. Each version is added
and none is removed. Spotter itself is on `main`: https://github.com/mikegrundvig/frc-spotter.
